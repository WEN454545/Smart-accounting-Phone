# 绝希 (Smart Bookkeeping)

一款 Android 记账应用，使用 Java 编写。支持收支记录、月度预算管理、日历视图、统计图表、多用户隔离，并可通过无障碍服务实现支付页面自动记账。

## 功能特性

- **手动记账** — 日期选择、分类、备注、金额录入；账单点击可编辑、左右滑动可删除；按日分组的账单列表
- **自动记账** — 基于无障碍服务监测微信、支付宝、拼多多、京东、云闪付等支付页面，自动提取金额与商户信息，弹出悬浮确认窗；确认窗支持「标准」与「灵动岛」两种风格
- **分类智能推荐** — 自动记账时根据历史账单备注学习用户分类习惯，推荐最可能的分类，越用越顺手
- **账单导入** — 支持 CSV 与微信 / 支付宝官方导出的 XLSX 账单流水文件，导入前可预览、勾选、自动推断分类
- **预算管理** — 按月设置总预算，支持自定义预警比例，超支发送系统通知
- **日历视图** — 月历上按日标注收支金额，点选日期联动查看当日账单，页面级滚动浏览
- **统计图表** — 饼图（分类占比）+ 柱状图（每日趋势）+ 趋势条视图，支持周 / 月 / 年三种周期
- **多用户隔离** — 多账户各自独立的数据空间，账单、预算、统计完全隔离；管理员可增删改其他用户
- **个性化** — 三套全局配色方案（Teal Sakura / Lavender Dream / Ocean Mint）、多页面自定义图片/视频背景、深色模式适配、桌面小组件

## 设计思想

### 双数据库分离

主库（`bill_database`）承载账单、预算与用户；自动记账库（`autobookkeep_db`）独立承载屏幕识别的流水与资产账户。两个数据源互不干扰，又能在分类学习时合并投票——既保证了自动记账数据的原始性，又不污染用户手工维护的账本。

### 无障碍驱动的自动记账

不依赖 Xposed、不依赖 Root，仅通过系统级 AccessibilityService 监听支付完成页面：从屏幕节点中提取金额、商户与时间，匹配内置关键词库完成预分类，再以悬浮确认窗交由用户一 tap 确认。识别结果先进自动记账库，用户确认后才进入正式账本，误识别永远不会弄脏真实账单。

### 基于加权回忆的分类学习

分类推荐不采用全量频次统计，而是模拟"最近的印象更深刻"：将屏幕关键词与两个数据库中各最近 7 条历史备注做子串匹配，按时间远近赋予 7→1 递减权重评分，取最高分作为推荐分类。用户改一次分类，学习池立即跟随，旧的错误习惯会被新习惯快速覆盖。

### 导入管线的鲁棒性

账单导入不做任何"理想化假设"：文件编码先严格校验 UTF-8、失败回退 GB18030（兼容中文 Windows 下 Excel 导出的 GBK 文件）；XLSX 按列引用坐标还原稀疏单元格，而非假设列连续；时间统一按账单源声明时区（UTC+8）落库，不受设备时区影响；导入前提供逐行预览与勾选，导入动作完全由用户掌控。

### 全链路的数据一致性

清空账单、删除账单、分类重命名等批量操作均同步维护两个数据库与图标映射的一致性：清空账单同时清理自动记账流水，避免学习池残留"幽灵分类"；分类重命名同步更新全部历史账单，杜绝旧名称残留在推荐结果里。

## 写在最后

这个项目从第一行代码到现在，本身就是一次不断试错、不断学习的过程——很多设计（比如分类学习、双库一致性）都是在踩坑之后慢慢打磨出来的。它还有不少可以做得更好的地方。

如果你也在学习 Android 开发，或者对记账应用的设计有自己的想法，非常欢迎一起交流：发现 bug 欢迎提 Issue，有更好的实现思路欢迎提 Pull Request，哪怕只是聊聊某段代码为什么这样写，也是很有价值的事。

希望这个项目能成为一块共同的试验田——我们一起把它做得更好用、更优雅，也在这条路上一起进步。
